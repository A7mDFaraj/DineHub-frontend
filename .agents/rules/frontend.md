# Frontend Guidelines

- Be smart, do not overengineer.
- Always use the best practices of UI building.
- Build reusable UI components.
- Always use `pnpm` instead of `npm` or `npx` or `yarn`.
- Use existing helpful libraries instead of creating everything from scratch.
- Ensure the result is modern, premium, and beautiful.
- Support dynamic customization (buyer logo, color themes) in public pages.
- **Prioritize Responsiveness:** Always ensure the UI is fully responsive. Clients will primarily access the app from mobile devices, and cashiers/staff will use small touch-screen machines. Build mobile-first.
